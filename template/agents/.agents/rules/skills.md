# Skills

- Use a skill only when it directly helps the task. Do not load one just because it is available.
- Shared skills are installed globally in `~/.agents/skills/<name>/SKILL.md`, not copied into this repo. Install steps: `docs/guides/setup.md`.
- Project skills: `.agents/skills/<name>/SKILL.md`. List each one under "Project skills".
- To use a skill: open its `SKILL.md` and follow it.
- No row below fits? Read the full table: `docs/guides/skills.md`.

## Main skills

| Task | Skill |
|---|---|
| New feature or creative work: explore the idea first | `brainstorming` |
| Turn a spec or idea into a plan | `writing-plans` |
| Carry out a written plan | `executing-plans` |
| Write tests before the code | `test-driven-development` |
| Bug or test failure: find the cause before fixing | `systematic-debugging` |
| Before saying work is done or fixed | `verification-before-completion` |
| Any coding task: smallest change that fully solves it | `ponytail` |
| Question about how the code works or how parts connect (needs a graph, see `graphify.md`) | `graphify` |
| Review a change | `ponytail-review` |
| Design, redesign, or polish any UI | `impeccable` |
| UI choices: style, color, fonts, layout | `ui-ux-pro-max` |
| Commit message (only when the user asks to commit) | `caveman-commit` |
| Write or edit instruction or rule files | `writing-for-agents` |

Cost and token skills (Caveman Cloud, `ponytail-gain`): only when the user asks.
